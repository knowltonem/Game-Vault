## How to Use This Guide

Every product listed in chronological in-game order. **OWNED** items are marked. Everything else needs purchasing. Buy in order — each cycle stands alone but the chronological order provides the best narrative experience.

**Two products per campaign:**
- **Campaign Expansion** — all scenarios (required to play)
- **Investigator Expansion** — all player cards (optional, but recommended for deckbuilding)

You can play any campaign with just the Campaign Expansion + Core Set cards. The Investigator Expansion adds new investigators and player cards.

## Budget Strategy

**Minimum to play all campaigns:** Buy only Campaign Expansions (~$440-480)
**Recommended:** Campaign + Investigator pairs (~$760-840)
**Complete:** Add all standalones (~$890-1000)

**Priority order for budget-tight purchases:**
1. Campaign Expansions first (you need these to play)
2. Investigator Expansions second (adds variety)
3. Standalones last (optional side content)
