# Legacy Investigators

← [[games/arkham-lcg/investigators/index|Back to All Investigators]]

Reference card data for the classic FFG campaign investigators (2017–2023). These are **not owned** — the vault's buying strategy picks up campaigns for story only. Files document signatures, weaknesses, and deckbuilding requirements (no official starter decks exist for these cycles).
