# Nora Warwick

> **Rogue** | Will 3 / Int 5 / Com 3 / Agi 2 | Health 7 / Sanity 8

## Overview

Academic archaeologist. Bless generator. Egyptian relic specialist.
Once per round: Spend 1 resource to add 1 bless token to the chaos bag.
Elder Sign: +1. Gain resources equal to the shroud value of your location.

## Deckbuilding

Requirements: The Warwick Collection ×1, The Family Debt ×1, 1 random basic weakness
