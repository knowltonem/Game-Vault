### Ability
```
<fre> Once per round: Look at the top 2 cards of the encounter deck.
Place them back in any order, or place one on top and one on the bottom.
```

### Elder Sign
```
<eld> +2. Gain 2 resources and draw 2 cards.
```

### Cultist Token
```
<cul> +0. Add 1 bless token to the chaos bag.
```

### Flavor (front)
```
"He knows things. He's always known things."
```

### Story (back)
```
"Dick Hallorann has had a hard life. Darey,
the overwatch, now Arkham. He calls it the
Shine. It brought him to Arkham. He doesn't
know why yet."
```

### Deckbuilding
```
Deck size: 30.
Mystic cards (level 0-5).
Survivor cards (level 0-5).
Neutral cards (level 0-5).
```
